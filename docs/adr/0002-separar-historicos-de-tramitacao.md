# Separar históricos de tramitação

O SICC manterá um histórico de tramitação para a formalização inicial do instrumento e um histórico independente para cada termo aditivo ou apostilamento. A separação permite identificar qual objeto estava sendo analisado em cada movimentação e evita misturar percursos administrativos distintos. Esses históricos são contínuos e não possuem, por si próprios, um estado terminal.
