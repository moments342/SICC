# Registrar alterações campo a campo

Termos aditivos e apostilamentos registrarão uma lista de alterações, cada uma com campo, valor anterior e valor novo. O campo pertencerá a um catálogo fechado baseado nos dados previstos pelo TCC, com validação de tipo e de permissão conforme a natureza da alteração. Esse modelo substitui textos livres ou patches opacos e permite recalcular o estado atual, explicar mudanças, retificar e cancelar registros.
